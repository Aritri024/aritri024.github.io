Project

Single-Camera Rotational CT System

Optical measurement hardware and automated image-processing workflow.

← Back to selected projects

Overview

This project involved building a single-camera rotational CT system and creating Python/MATLAB processing workflows for high-volume experimental image analysis.

Problem

The experimental program required a practical computed-tomography measurement setup and a repeatable method for processing large image sets across test conditions.

Approach

  • Built a single-camera rotational CT mechanism.
  • Automated Python/MATLAB workflows for image processing, calibration, statistical analysis, and visualization.
  • Used RCA and FMEA to improve reliability and safety during testing.

Results

  • Automated processing handled 200-300 images per condition.
