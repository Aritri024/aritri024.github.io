Project

Minichannel Heat-Sink Thermal-Fluid Optimization

CFD, mesh convergence, and geometry evaluation for thermal management.

← Back to selected projects

Overview

At IIT Kanpur, I performed a parameterized CFD study of minichannel heat-sink performance using ANSYS Fluent.

Problem

The goal was to evaluate how modified internal insert geometry affected minichannel thermal-fluid performance while ensuring the numerical results were independent of mesh size.

Approach

  • Ran parameterized mesh-convergence studies in ANSYS Fluent.
  • Evaluated modified internal insert geometries using CFD results.

Results

  • Modified insert geometry improved minichannel thermal-fluid performance by up to 28%.
