# Aritri Halder portfolio website

A simple static website designed for GitHub Pages.

## Files
- `index.html` - main website
- `styles.css` - all visual styling
- `project-20kw-furnace.html` - 20 kW experimental system page
- `project-ct-system.html` - rotational CT system page
- `project-minichannel.html` - minichannel CFD page
- `project-fsi.html` - fluid-structure interaction page
- `project-template.html` - duplicate this when adding a new project
- `cv.html` - web CV
- `Aritri_Halder_CV.pdf` - downloadable PDF CV generated from the same resume content

## Updating content
1. Edit text directly in the HTML file.
2. To replace a project placeholder, insert an `<img>` tag inside the placeholder area, or create an `assets/` folder later and reference the image path.
3. To add a project, copy `project-template.html`, rename it, replace the bracketed text, and add a card/link to `index.html`.
4. Publication links marked `[add link]` are intentionally placeholders because no URL/DOI was present in the source resume.
5. Google Scholar is intentionally left as a placeholder because no profile URL was present in the source resume.

## GitHub Pages
Upload these files to the root of `aritri024.github.io`, commit them to `main`, then go to **Settings -> Pages** and choose **Deploy from a branch -> main -> /(root)**.
